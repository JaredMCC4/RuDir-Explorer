# RuDir Explorer

RuDir Explorer is a planned cross-platform file explorer and Rust learning project. It is in the documentation stage; no application or release is available yet.

The 0.1 goal is a daily-use explorer for Windows and Linux, with a shared Rust core, a focused CLI and an Iced GUI. Planned capabilities include navigation, search, file operations and recovery. Platform integration and recovery guarantees depend on prototypes and fault testing.
